# Fonts

`NotoNastaliqUrdu-Regular.ttf` and `NotoNastaliqUrdu-Bold.ttf` (declared in
`pubspec.yaml`, used via `AppTheme.urdu` in
`lib/core/theme/app_theme.dart`) were fetched from Google Fonts
(`fonts.gstatic.com/s/notonastaliqurdu/v23/...`), version v23.
